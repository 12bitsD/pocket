# Calendar 领域说明（日程 · 月历 · 统一 Todo）

状态：**精简定稿版，2026-11-23**

**Pocket Calendar** 通过单层三栏（`[d] 今日日程 / [m] 月历 / [t] Todo`）统一管理日常日程、手机闹钟与外部 Agent 定时任务，视觉规范见 [Pocket 设计标准](../design-standard.md)。

## 1. 三个核心界面职责

- **`[d]` 今日日程**：聚焦展示当天日程（下一场主角卡 + 今日其余场次），同一天时段交叉时标记「时间重叠」，支持提前强提醒（同步触发手机系统闹钟）。
- **`[m]` 月历**：7 列等宽月历，区分强提醒日程与普通日程，点选任意日期查看或新建。
- **`[t]` Todo**：共用一套输入框与时间选择器，按指派对象分流：
  - **仅待办（`none`）**：普通待办事项，做完打勾归档；
  - **`@me`**：手机系统闹钟准点响铃（收到手机真实回执后显示 `EXECUTED`）；
  - **`@agent_id`**：云端按设定时间把该条文本发给对应 Agent 执行，回传摘要直接展示在原条目下方。

## 2. 关键交互与保护规则

- **单次与循环自动区分**：单次事项左侧为完成打勾框（支持选具体日期）；每天/工作日/每周循环项左侧为 `ON / OFF` 启停开关，支持「跳过下一次」。
- **本机锁（`LOCKED`）**：在手机本机开启锁定的闹钟，仅允许在手机本机修改或关闭，拦截网页或 Agent 的远程改动。
- **锁屏响铃体验**：手机到点弹出全屏大字响铃页，提供「关闭本次」与「10 分钟后再响」两个操作；超时未按记为 `MISSED`。

# Pocket 整体开发方案与分步路线（Development Plan）

状态：**正式定稿，2026-11-23**

本文档汇总 Pocket 第一阶段主线应用 **Pocket Calendar（日程、闹钟与 Agent 待办合一）** 与共享私有云端 **Pocket Cloud** 的完整开发方案及推进步骤。后端建表与代码级细则见 [后端实施手册](cloud/implementation-plan.md)。

---

## 一、整体方案概览

1. **产品构成**：
   - **Pocket Calendar**（当前开发主线）：通过 `今日日程 / 月历 / Todo` 三栏统一管理日常日程、`@me` 手机闹钟与 `@agent` 定时任务。
   - **Pocket Notes**（后续独立阶段）：独立的笔记应用，支持按篇授权给指定 Agent 读取。
   - **Pocket Cloud**：两个独立应用共用的个人私有云端（单服务进程 + PostgreSQL 数据库），提供多端实时同步、定时唤醒外部 Agent 与命令行调试胶水层。
2. **终端与发布形态**：
   - **网页端**：模块化前端界面直连私有云端，供电脑端高效编辑日程、Todo 与 Agent 配置。
   - **安卓端**：复用同一套前端界面打包为独立 APK，配合薄层 Kotlin 原生插件实现开机未解锁可读存储、系统级准点响铃、锁屏全屏唤醒与权限一键自检，构建产物统一发布至 **GitHub Releases**。
   - **CLI 胶水层**：复用同一套后台接口提供命令行操作与实时调试能力，同时方便本地 AI 直接调用。

---

### Step 1：后台底座、账号配对、Agent 配置与首批 CLI
**做什么**：
- 搭建 `cloud/` 服务骨架、数据库连接池、顺序迁移器与密钥加解密模块；
- 实现初始主密钥登录、5 分钟有效的 **6 位手机配对码** 生成与兑换；
- 实现按读写开关签发受限 Agent 密钥、保存外部 Agent 名称与加密调用密钥、按 `request_id` 去重；
- 交付配套 CLI：`pair create/claim`、`token create/list/revoke`、`agent set/list/revoke`。

**验收标准**：
- 主密钥登录、6 位码换取手机凭证、受限密钥权限检查与加密存储测试全部通过。

---

### Step 2：日程、统一 Todo、定时唤醒 Agent 与触发调试 CLI
**做什么**：
- 实现日程增删改查、重复日程按日期区间展开、同日时间冲突自动标记与提前强提醒状态记录；
- 实现统一 Todo 增删改查（普通待办 / `@me` 响铃 / `@agent` 定时任务）、选具体日期、单次完成与周期开关、跳过下一次，以及手机端专享修改权的**本机锁**；
- 实现后台定时循环：到点自动将 `@agent` 任务通过 HTTP 发送至目标网址，支持失败退避重试与一次性回调密钥回传结果摘要挂回原 Todo；
- 交付配套 CLI：`event list/add/delete`、`todo list/add/toggle/delete`、`trigger <todo_id>`（立即手动触发一次指定 Agent 任务并打印结果）。

**验收标准**：
- 日程冲突标记、本机锁保护、本地测试 Agent 定时接收任务、失败重试与摘要回写全链路测试通过。

---

### Step 3：多端实时同步、响铃回执与同步调试 CLI
**做什么**：
- 实现按序变更日志记录与长连接实时推送；
- 实现断网重连自动补齐缺失变更、手机设好系统闹钟后回传生效状态（`EXECUTED`）、离线本机锁优先覆盖与吊销设备即时踢下线；
- 交付配套 CLI：`sync watch`（终端实时滚动监听同步流）、`sync ack`（命令行模拟手机回传响铃生效状态）；
- 将真实 PostgreSQL 数据库测试与代码规范检查接入 GitHub Actions 自动验证。

**验收标准**：
- 多端并发改动实时同步、断线补齐、模拟手机回执推进状态与全仓自动化检查全部零错误通过。

---

### Step 4：前端模块化与网页端正式接入
**做什么**：
- 用轻量 `Vite` 将单文件原型拆分为正式前端模块，抽出共享接口请求与长连接同步层；
- 将 `apps/calendar` 接通真实 `pocket-cloud` 后台（主密钥登录、6 位配对码生成、日程与 Todo 实时同步、Agent 绑定与权限开关配置）。

**验收标准**：
- 浏览器打开网页端即可完成真实日程排期、配真实外部 Agent 跑通定时投递并在界面实时看到回传摘要。

---

### Step 5：安卓客户端打包、真机响铃与 GitHub Release 发布
**做什么**：
- 接入 Capacitor 安卓容器与 Kotlin 原生响铃插件：设备安全区本地 SQLite 存储、手机重启未解锁自动恢复闹钟、系统精确闹钟注册、黑屏全屏响铃页（关闭本次 / 10 分钟后再响）与真机 4 项权限自检跳转卡；
- 接通手机端 6 位配对码绑定、离线操作队列与闹钟生效回执上报；
- 打包 `Pocket Calendar` 正式 APK，通过版本标签（`calendar-v*`）发布至 **GitHub Releases**。

**验收标准**：
- 真机安装 Release APK 后完成扫码/输码配对、锁屏黑屏准点响铃、10 分钟贪睡、断网新建闹钟与重启恢复验收。
